# Build A Tool — Project Brief

## Vision
A community platform where non-technical people (starting in Nigeria) can:
- Suggest tools/ideas they want built
- Get matched with a real human technical expert (mentor)
- Vibecode together with AI agents while the human expert guides, prompts the AI accurately, monitors output, and adjusts based on the founder’s vision
- Upvote/vote on ideas so the community can collectively decide which tools get priority-built (public good tools)
- Book 1:1 consultations with technical people

## Core Value
Make vibecoding safe and fun for complete beginners. The AI agents do 80 % of the heavy lifting, but the human expert is always there to prevent hallucinations, translate business needs into precise prompts, and make the final product actually match what the non-tech person wants.

## Target Audience (Phase 1)
Primarily Nigerians (tech-curious students, side-hustlers, small business owners, creatives in Lagos, Abuja, PH, Ibadan, etc.). English + Pidgin-friendly. Scale to Africa/global later.

## MVP Features (must-have)
1. User accounts (non-tech founders + technical mentors)
2. Idea submission form + public feed with upvotes
3. Matching system (simple: request mentor → available mentors accept)
4. Project workspace (chat + AI agent panel where mentor + founder + Agency agents collaborate)
5. Voting/polls for “Community Tool of the Month”
6. Booking calendar for 1:1 consultations
7. Nigerian-first polish (Naira display, mobile money hints, local time, etc.)

## Tech Preferences
None — recommend the fastest, cheapest, most maintainable modern stack for a real-time community MVP.

## Success Metrics (MVP)
- 100 idea submissions in first 30 days
- 20 successful mentor matches
- At least 3 tools actually shipped via the platform

Keep everything simple, beautiful, and mobile-first. All UI must follow the Premium UI Architect (Jobs/Ive) philosophy: inevitable simplicity, Nigeria-first mobile experience.
